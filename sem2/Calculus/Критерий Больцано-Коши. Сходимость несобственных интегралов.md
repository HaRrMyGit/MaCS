# Формулировка
$-\infty < a < b \le +\infty \quad f \in R_{loc}[a, b)$
Тогда $\int_a^{\to b} f$ сход $\Leftrightarrow \forall \varepsilon > 0 \ \exists \Delta \in (a, b) : A, B \in (\Delta, b) \Rightarrow \left| \int_A^B f \right| < \varepsilon$

$\Leftrightarrow \forall \varepsilon > 0 \ \exists \Delta \in (a, b) : \forall A, B \in (\Delta, b) \Rightarrow \underbrace{|\varphi(B) - \varphi(A)|} < \varepsilon$
