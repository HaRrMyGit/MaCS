# Формулировка
$\gamma \in C([a, b] \to \mathbb{R}^n)$     $c \in (a, b) \qquad \gamma_1 = \gamma|_{[a, c]} \qquad \gamma_2 = \gamma|_{[c, b]}$
Тогда: $S_{\gamma} = S_{\gamma_1} + S_{\gamma_2}$
# Доказательство
Обозн. $S_1 = S_{\gamma_1}, \quad S_2 = S_{\gamma_2}$.
$\sqsupset \tau_1$ и $\tau_2$ — дробления $[a, c]$ и $[c, b]$ $\Rightarrow \tau = \tau_1 \cup \tau_2$ — дробление $[a, b]$
$l_{\tau_1} + l_{\tau_2} = l_{\tau} \overset{\text{опр}}{\le} S_{\gamma} \quad \left| \begin{aligned} \sup_{\tau_1} l \\ \sup_{\tau_2} l \end{aligned} \right.$ по определению [[Длина пути]]
$\Rightarrow \begin{cases} S_1 + l_{\tau_2} \le S_{\gamma} \\ l_{\tau_1} + S_2 \le S_{\gamma} \end{cases} \quad \Rightarrow \quad S_1 + S_2 \le S_{\gamma}$
## докажем $S_{\gamma} \le S_1 + S_2$
достаточно доказать: $\forall \tau \quad l_{\tau} \le S_1 + S_2$
$\sqsupset \tau$ — дробление $[a, b]$
Если оно содержит $c$, то $\tau = \tau_1 \cup \tau_2$, где $\tau_1, \tau_2$ дробления $[a, c], [c, b]$
$l_{\tau} = l_{\tau_1} + l_{\tau_2} \le S_1 + S_2$
Если $c \notin \tau$, то добавим его туда:
положим $\tau^* = \tau \cup \{c\}$
$\sqsupset c \in (t_k, t_{k+1})$
$$l_{\tau} = \sum_{i=0}^{k-1} |\gamma(t_{i+1}) - \gamma(t_i)| + |\gamma(t_{k+1}) - \gamma(t_k)| + \sum_{i=k+1}^{n-1} |\gamma(t_{i+1}) - \gamma(t_i)| \le$$
$$\le \sum_{i=0}^{k-1} |\gamma(t_{i+1}) - \gamma(t_i)| + |\gamma(c) - \gamma(t_k)| + |\gamma(t_{k+1}) - \gamma(c)| + \dots =$$
$$= l_{\tau^*} \le S_1 + S_2 \text{(по доказанному)}$$
$$\square$$
