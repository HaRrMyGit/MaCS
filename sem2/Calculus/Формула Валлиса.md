# Формулировка
$\pi = \lim_{n \to \infty} \frac{1}{n} \left( \frac{(2n)!!}{(2n-1)!!} \right)^2$
# Доказательство
$\forall x \in (0; \frac{\pi}{2}) \quad 0 < \sin x < 1_{\text{}} \Rightarrow \forall n \in \mathbb{N} \quad {\sin^{2n+1} x < \sin^{2n} x < \sin^{2n-1} x}{\text{}}$ $\Rightarrow J_{2n+1} < J_{2n} < J_{2n-1}$
По [[Лемма 4.4.1]] $$\frac{(2n)!!}{(2n+1)!!} < \frac{(2n-1)!!}{(2n)!!} \frac{\pi}{2} < \frac{(2n-2)!!}{(2n-1)!!} \Leftrightarrow \left( \frac{(2n)!!}{(2n-1)!!} \right)^2 \frac{1}{2n+1} < \frac{\pi}{2} < \left( \frac{2n!!}{(2n-1)!!} \right)^2 \cdot \frac{1}{2n}$$
$\sqsupset x_n = \left( \frac{(2n)!!}{(2n-1)!!} \right)^2 \frac{1}{n}:$ $\pi < x_n < \frac{2n+1}{2n} \pi$ $\Rightarrow x_n \to \pi$
$$\square$$
