# Формулировка
$\sqsupset f, g$ — возрастают/убывыют на $[a, b]$ (одна возрастает, другая убывает)
Тогда $\frac{1}{b-a} \int_a^b fg \le \left(\frac{1}{b-a} \int_a^b f\right) \left(\frac{1}{b-a} \int_a^b g\right)$
# Доказательство
$A = \frac{1}{b-a} \int_a^b f$, $\sqsupset E = \{x \in [a, b] : f(x) > A\}$
$E \neq \emptyset$ т.к. иначе $f(x) > A \quad \forall x \in [a, b] \Rightarrow A > A$ — противоречие.
$\sqsupset c = \sup E$, Тогда $$\begin{cases} A-f \ge 0 & g \ge g(c) \text{ на } [a, c] \\ A-f \le 0 & g \le g(c) \text{ на } [c, b] \end{cases}$$$$\Rightarrow \int_a^b (A-f)g = \int_a^c (A-f)g + \int_c^b (A-f)g \ge$$ $$ \ge g(c)\int_a^c (A-f) + g(c)\int_c^b (A-f) = g(c)\int_a^b (A-f) = 0$$
$$\square$$
# Следствие
$a, b \in \mathbb{R}^n$, $a_1 \le \dots \le a_n$, $b_1 \ge \dots \ge b_n$
Тогда $\frac{1}{n} \sum_{k=1}^n a_k b_k \le \left(\frac{1}{n} \sum_{k=1}^n a_k\right) \left(\frac{1}{n} \sum_{k=1}^n b_k\right)$
