# Формулировка
$\sqsupset \gamma \in C^{(1)}([a, b] \to \mathbb{R}^n) \implies \gamma$ спрямляем и $S_\gamma = \int_a^b |\gamma'|$
# Доказательство
## Спрямляемость
$\sqsupset \Delta = [\alpha, \beta] \subset [a, b]$
Возьмем дробление $\eta = \{u_k\}_{k=0}^n$ отрезка $\Delta$
$$l_\eta = \sum_{k=0}^{n-1} |\gamma(u_{k+1}) - \gamma(u_k)| = \sum_{k=0}^{n-1} \sqrt{\sum_{i=1}^n (\gamma_i(u_{k+1}) - \gamma_i(u_k))^2}$$
По теореме Лагранжа $\forall i \ \forall k \ \exists c_{ik} \in (u_k, u_{k+1}) : \gamma_i(u_{k+1}) - \gamma_i(u_k) = \gamma_i'(c_{ik})\Delta u_k$
$$\Rightarrow l_\eta = \sum_{k=0}^{n-1} \sqrt{\sum_{i=1}^n \gamma_i'(c_{ik})^2} \Delta u_k$$
Обозначим: $m_\Delta^{(i)} = \min_{t \in \Delta} |\gamma_i'(t)| \qquad M_\Delta^{(i)} = \max_{t \in \Delta} |\gamma_i'(t)|$ (существует в силу непрерывности)
$$m_\Delta = \sqrt{\sum_{i=1}^n (m_\Delta^{(i)})^2} \qquad M_\Delta = \sqrt{\sum (M_\Delta^{(i)})^2}$$
$$m_\Delta \le \sqrt{\sum_{i=1}^n \gamma_i'(c_{ik})^2} \le M_\Delta$$
$$m_\Delta \cdot \sum_{k=0}^{n-1} \Delta u_k \le l_\eta \le M_\Delta \sum_{k=0}^{n-1} \Delta u_k$$
$$m_\Delta(\beta - \alpha) \le l_{\gamma|_\Delta} \le M_\Delta(\beta - \alpha)$$
В частности, при $\Delta = [a, b]$ отсюда следует спрямляемость $\gamma$.
## Равенство $S_\gamma = \int_a^b |\gamma'|$
$\tau = \{t_k\}_{k=0}^n$ — дробление $[a, b]$
Обозначим $m_k = m_{[t_k, t_{k+1}]} \qquad M_k = M_{[t_k, t_{k+1}]}$
$$ m_k \Delta t_k \le S_{\gamma}|_{[t_k, t_{k+1}]} \le M_k \Delta t_k \quad$$
$\forall t \in [t_k, t_{k+1}] \qquad m_k \le |\gamma'(t)| \le M_k \quad \left| \int_{t_k}^{t_{k+1}} \dots dt \right.$
$$m_k \Delta t_k \le \int_{t_k}^{t_{k+1}} |\gamma'| \le M_k \Delta t_k$$
По [[Лемма 4.6.2|аддитивности длины пути]]:

$$\sum_{k=0}^{n-1} m_k \Delta t_k \le S_{\gamma} \le \sum_{k=0}^{n-1} M_k \Delta t_k $$
По [[Аддитивность интеграла по отрезку|аддитивности интеграла]]:
$$ \sum_{k=0}^{n-1} m_k \Delta t_k \le \int_a^b |\gamma'| \le \sum_{k=0}^{n-1} M_k \Delta t_k $$
Не является интегральными суммами $\int_a^b |\gamma'| \quad \left( \max \sqrt{\sum (\dots)^2} \neq \sqrt{\sum (\max \dots)^2} \right)$
$$ \sqsupset M_{\Delta} - m_{\Delta} = \frac{M_{\Delta}^2 - m_{\Delta}^2}{M_{\Delta} + m_{\Delta}} = \frac{\sum_{i=1}^m \left( (M_{\Delta}^{(i)})^2 - (m_{\Delta}^{(i)})^2 \right)}{M_{\Delta} + m_{\Delta}} = $$
$$ = \sum_{i=1}^m \left( M_{\Delta}^{(i)} - m_{\Delta}^{(i)} \right) \underbrace{\frac{M_{\Delta}^{(i)} + m_{\Delta}^{(i)}}{M_{\Delta} + m_{\Delta}}}_{\le 1} \le \sum_{i=1}^m \left( M_{\Delta}^{(i)} - m_{\Delta}^{(i)} \right) $$
Если $M_{\Delta} = m_{\Delta} = 0$, то неравенство очевидно
Возьмем $\varepsilon > 0 \quad \forall i \in [1:m] \quad |\gamma_i'|$ непрерывно на $[a, b] \Rightarrow$ по теореме Кантора о равномерно непрерывных на $[a, b]$
$\Rightarrow \exists \delta_i > 0 : \forall [\alpha, \beta] \subset [a, b] : \beta - \alpha < \delta_i \Rightarrow M_{\Delta}^{(i)} - m_{\Delta}^{(i)} < \frac{\varepsilon}{(b-a)m}$
Положим $\delta = \min_{1 \le i \le m} \delta_i$ $\Rightarrow \forall \text{дробление } \Delta \text{ пути } < \delta$
$$M_{\Delta} - m_{\Delta} \le \sum_{i=1}^m (M_{\Delta}^{(i)} - m_{\Delta}^{(i)}) \le m \cdot \frac{\varepsilon}{(b-a)m} = \frac{\varepsilon}{b-a}$$
$$\left| S_{\gamma} - \int_a^b |\gamma'| \right| \le \sum_{k=0}^{n-1} M_k \Delta t_k - \sum_{k=0}^{n-1} m_k \Delta t_k = \sum_{k=0}^{n-1} (M_k - m_k) \Delta t_k < \frac{\varepsilon}{b-a} \cdot (b-a) = \varepsilon$$
$$\square$$
# Следствие 1
При $m=2$ $\gamma = (x(t), y(t)) \in C^{(1)}([a, b] \to \mathbb{R}^2) \implies S_{\gamma} = \int_a^b \sqrt{x'^2 + y'^2}$
# Следствие 2
Длина графика $f \in C^{(1)}([a, b] \to \mathbb{R}^2) \to$ график $f$ $\Gamma_f$ спрямляем и его длина: $S_{\Gamma_f} = \int_a^b \sqrt{1 + f'^2}$
# Следствие 3
Если путь задается в полярных коорд. уравнением $r = f(\varphi)$, где $f \ge 0, \ f \in C^{(1)}[\alpha, \beta]$, то $S_{\gamma} = \int_{\alpha}^{\beta} \sqrt{f^2 + f'^2}$
