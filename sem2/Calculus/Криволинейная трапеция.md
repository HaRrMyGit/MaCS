#Глава_4 #Параграф_6 #Определение
$f: [a, b] \to [0, +\infty)$. Подграфик $f$ — мн-во $Q_f = \{(x, y) \in \mathbb{R}^2 : x \in [a, b], 0 \le y \le f(x)\}$
Если $f$ непрерывно, то подграфик $f$ — криволинейная трапеция
$f \in R[a, b], f \ge 0$
$\exists \tau = \{x_k\}_{k=0}^n$ — дробление $[a, b] : a = x_0 < x_1 < \dots < x_n = b$
$m_k = \inf_{[x_k, x_{k+1}]} f \qquad M_k = \sup_{[x_k, x_{k+1}]} f$
$s_\tau = \sum_{k=0}^{n-1} m_k \Delta x_k$
$S_\tau = \sum_{k=0}^{n-1} M_k \Delta x_k$
$f$ — интегрируема $\Rightarrow \sup_\tau S_\tau = \inf_\tau \bar{S}_\tau = \int_a^b f$
$s_\tau \le S(Q_f) \le S_\tau \Rightarrow S(Q_f) = \int_a^b f$
