# Формулировка
Длины эквивалентных путей равны
# Доказательство
$\gamma: [a, b] \to \mathbb{R}^n \qquad \tilde{\gamma}: [\alpha, \beta] \to \mathbb{R}^n$
$\gamma \sim \tilde{\gamma} \Leftrightarrow \exists u: [a, b] \xrightarrow{на} [\alpha, \beta]$ строго возр.: $\gamma = \tilde{\gamma} \circ u$
$\sqsupset\tau = \{t_k\}_{k=0}^n$ - дробление $[a, b]$
Положим $\tilde{t}_k = u(t_k) \Rightarrow \tilde{\tau} = \{\tilde{t}_k\}_{k=0}^n$ - дробление $[\alpha, \beta]$
$$l_{\tau} = \sum_{k=0}^{n-1} |\gamma(t_{k+1}) - \gamma(t_k)| = \sum_{k=0}^{n-1} |\tilde{\gamma}(u(t_{k+1})) - \tilde{\gamma}(u(t_k))| = l_{\tilde{\tau}} \le S_{\tilde{\gamma}}$$
$$l_{\tau} \le S_{\tilde{\gamma}} \implies S_{\gamma} \le S_{\tilde{\gamma}}$$
Меняя $\gamma \sim \tilde{\gamma}$ ролями, получаем $S_{\tilde{\gamma}} \le S_{\gamma}$
$$\square$$
