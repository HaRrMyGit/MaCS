# Формулировка
$f, g \in C[a, b] \quad p \ge 1$, тогда $\left( \int_a^b |f+g|^p \right)^{\frac{1}{p}} \le \left( \int_a^b |f|^p \right)^{\frac{1}{p}} + \left( \int_a^b |g|^p \right)^{\frac{1}{p}}$
# Доказательство
Аналогично Гёльдерлу, но нер-ву Минковского $$\left( \sum_{k=0}^{n-1} |a_k + b_k|^p \right)^{\frac{1}{p}} \le \left( \sum_{k=0}^{n-1} |a_k|^p \right)^{\frac{1}{p}} + \left( \sum_{k=0}^{n-1} |b_k|^p \right)^{\frac{1}{p}}$$
$$\square$$
