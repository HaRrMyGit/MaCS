# Формулировка
$\sqsupset n \in \mathbb{Z}_{+}, \ f \in C^{n+1} <a,b>, \ x,x_0 \in <a,b>$ 
Тогда $f(x) = \sum^n_{k=0} \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + \frac{1}{n!}\int^x_{x_0}f^{(n+1)}(t)(x-t)^ndt$
# Доказательство
База индукции $(n=0) \equiv$ [[Формула Ньютона-Лейбница]]:
$$f(x) =f(x_0) + \int^x_{x_0}f'(t)dt$$
Пусть верно для $n-1$, докажем для $n$
$$\int^x_{x_0}f^{(n)}(t)\frac{(x-t)^{n-1}}{(n-1)!}dt = \int^x_{x_0}f^{(n)}(t)d\left(-\frac{(x-t)^n}{n!}\right) = $$
$$= -\frac{1}{n!}[f^{(n)}(t)(x-t)^n]^x_{t = x_0} + \frac{1}{n!}\int^x_{x_0}f^{(n+1)}(t)(x-t)^ndt =  $$
$$\frac{f^{(n)}(x_0)}{n!}(x-x_0)^n + \frac{1}{n!}\int^x_{x_0}f^{(n+1)}(t)(x-t)^ndt \Rightarrow$$
$$\Rightarrow f(x) = \sum^n_{k=0}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + \frac{1}{n!}\int^x_{x_0}f^{(n+1)}(t)(x-t)^ndt  $$
$$\square$$
