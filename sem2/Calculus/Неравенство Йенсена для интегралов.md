# Формулировка
$f$ вып. и непр. на $\langle A, B \rangle$, $\varphi \in C([a, b] \to \langle A, B \rangle)$, $\lambda \in C([a, b] \to [0, +\infty))$, $\int_a^b \lambda = 1$
Тогда $f\left( \int_a^b \lambda \varphi \right) \le \int_a^b \lambda (f \circ \varphi)$
# Доказательство
$c = \int_a^b \lambda \varphi$, $E = \{ x \in [a, b] : \lambda(x) > 0 \}$
$$m = \inf_E \varphi \quad M = \sup_E \varphi$$(по т. Вейерштрасса $m, M \in \mathbb{R}$)
если $m = M$, то $\varphi = \text{const}$ на $E$, то $c = m$ и $f(c) = f(m)$
если $m < M$, $c \in (m, M) \Rightarrow c \in \langle A, B \rangle$
ф-ция $f$ имеет в $c$ опорную прямую, т.к. $c$ лежит в $\langle A, B \rangle$
по опр. прямой $f(c) = \alpha c + \beta$
$$f(t) \ge \alpha t + \beta \quad \forall t \in \langle A, B \rangle

  

\Rightarrow f(c) = \alpha c + \beta = \alpha \int_a^b \lambda \varphi + \beta \int_a^b \lambda = \int_a^b \lambda (\alpha \varphi + \beta) \le \int_a^b \lambda (f \circ \varphi)$$
$$\square$$
