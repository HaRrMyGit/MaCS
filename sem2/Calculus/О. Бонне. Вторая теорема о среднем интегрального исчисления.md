# Формулировка
$f \in C[a,b]$, $g \in C^{(1)}[a,b]$ — монотонна на $[a,b]$,
Тогда $\exists c \in [a,b]:$ $\int_a^b fg = g(a)\int_a^c f + g(b)\int_c^b f$
# Доказательство
$\sqsupset F(x) = \int_a^x f \Rightarrow F' = f, F(a) = 0$
$$\int_a^b fg = \int_a^b gF' = Fg\big|_a^b - \int_a^b Fg' = g(b)\int_a^b f - \int_a^b Fg'$$
т.к. $g$ монотонна, $g'$ сохр. знак на $[a,b]$
по общ. [[Первая теорема о среднем интегрального исчисления|первой т. о среднем]] $\exists c \in [a,b]: \int_a^b Fg' = F(c)\int_a^b g' = (g(b) - g(a))\int_a^c f$
группируя по $g(b)$ и по [[Аддитивность интеграла по отрезку|адд. интеграла]]:
$$\int_a^b fg = g(b)\int_a^b f - (g(b) - g(a))\int_a^c f = g(a)\int_a^c f + g(b)\int_c^b f$$ 
$$\square$$
$\int^a_b$ - [[Определённый интеграл]]
